# T‑SQL Querying — Chapters, Examples, and Exercises

**Edition:** 2025-11-01  

**Compatibility:** SQL Server 2019/2022, ANSI‑compliant where possible.

## Structure
- `chapters/` — 12 chapter scripts with commented examples.
- `exercises/` — practice tasks you can run after loading chapter 1.
- `solutions/` — reference answers (try the exercises first!).

## Quick Start
1. Open `chapters/01_select_basics.sql` and execute it to create demo tables.
2. Work through chapters in order.
3. Attempt each file in `exercises/` before peeking at `solutions/`.

## Notes
- Examples emphasize **SARGable** predicates, clean style, and predictable results.
- Everything uses temporary/permanent demo tables so it’s self‑contained.
- Feel free to adapt to Northwind/AdventureWorks by replacing table sources.
